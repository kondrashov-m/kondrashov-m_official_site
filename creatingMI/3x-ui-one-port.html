    1. Установка панели 3x-ui на сервер

    Подключитесь к серверу командой ssh root@1.1.1.1, обновите систему и установите необходимые пакеты.

    

    
    Установите выбранную версию панели. По умолчанию используется последняя версия из основного репозитория.
    
    
    

    
    Во время установки задайте порт панели, выберите базу данных, параметр установки сертификатов. После установки вы увидите ссылку на панель и доступы. Дополнительные параметры управления вы можете увидеть, выполнив команду x-ui.

    2. Создание подключений vless/hysteria
    
    
    Создайте инбаунд в разделе Подключения, указав основные параметры (остальное можно оставить по умолчанию):
    
    
    
      
    VLESS TCP
    
      
    HYSTERIA2
    
    
    

    
    
      
    
        
        Обязательные параметры: VLESS TCP
      
    
      
    
    
    

    
    

    
    
    
    3. Создание основного инбаунда на 443 порту
