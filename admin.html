Берлога — Админка инструкций

Правка протоколов и инструкций для оверлеев на berloga.html — без правки кода.

⚠️ Эта страница работает только локально, у тебя на компьютере. Она напрямую читает/пишет файл berloga/protocols.json через File System Access API (Chrome/Edge) — открой этот файл в браузере (двойным кликом или через Live Server) и нажми «Открыть protocols.json».

Сайт лежит на GitHub Pages статически, поэтому эта страница ничего не меняет на живом сайте сама по себе. После правок и сохранения — закоммить и запушь изменённый berloga/protocols.json в репозиторий, только тогда изменения появятся на сайте.
