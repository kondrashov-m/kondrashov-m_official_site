Админка сайта

Правка данных для berloga.html, automatics.html, проектов на главной и версии сайта — без правки кода.

⚠️ Эта страница работает только локально, у тебя на компьютере. При запуске через локальный сервер (Live Server и т.п.) она сама подгружает нужный JSON выбранной вкладки — ничего нажимать не нужно. Кнопка «Перезаписать файл» пишет правки сразу на диск (при первом нажатии браузер один раз попросит указать сам файл и запомнит разрешение). Если браузер не поддерживает прямую запись — используй «Скачать JSON» и замени файл вручную.

Сайт лежит на GitHub Pages статически, поэтому эта страница ничего не меняет на живом сайте сама по себе. После сохранения — закоммить и запушь изменённый файл (berloga/protocols.json, automatics/lectures.json, projects/projects.json, а для версии — footer.html, index.html, berloga.html) в репозиторий, только тогда изменения появятся на сайте.
