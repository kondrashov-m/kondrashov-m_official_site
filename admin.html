Берлога — Админка инструкций

Правка протоколов и инструкций для оверлеев на berloga.html — без правки кода.

⚠️ Эта страница работает только локально, у тебя на компьютере. При запуске через локальный сервер (Live Server и т.п.) она сама подгружает berloga/protocols.json для просмотра/правки — ничего нажимать не нужно.

Кнопка «Перезаписать файл» пишет правки сразу на диск. При первом нажатии (если файл ещё не был открыт через «Открыть protocols.json») она попросит один раз указать сам файл — браузер (Chrome/Edge) запомнит разрешение на запись именно в него, и при следующих визитах перезапись будет идти автоматически (может появиться небольшая кнопка «Разрешить прямую запись» — это разовое подтверждение браузера).

Сайт лежит на GitHub Pages статически, поэтому эта страница ничего не меняет на живом сайте сама по себе. После сохранения — закоммить и запушь изменённый berloga/protocols.json в репозиторий, только тогда изменения появятся на сайте.
