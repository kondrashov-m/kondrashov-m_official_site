# SEKRET

Сюда кладутся реальные файлы VPN-протоколов, которые раздаёт страница [`berloga.html`](../berloga.html).

Эта папка в `.gitignore` — файлы отсюда не попадают в git-историю публичного репозитория, но на самом сайте остаются доступны по прямой ссылке всем, кто её знает (без пароля). Заливай реальные конфиги прямо на хостинг, а не через git-коммит, если не хочешь, чтобы они когда-нибудь засветились в истории репо.

## Имена файлов, которые уже ждёт страница

- `ios-httpinjector.ehi` — конфиг HTTP Injector для iPhone
- `android-httpinjector.ehi` — конфиг HTTP Injector для Android

Положи файлы с этими именами сюда — кнопки «Скачать конфиг» на странице заработают сами.

## v2rayTun (vless://...)

Подписочные ссылки для v2rayTun хранятся не файлами, а прямо в массиве `PROTOCOLS` в конце `berloga.html` — замени там `REPLACE-WITH-YOUR-LINK` на реальные `vless://...`. Держи ссылку чисто на латинице/ASCII (как и положено URI) — кириллица в ней ломает генерацию QR-кода на странице.

Хочешь добавить ещё протокол (другой формат, другое приложение) — допиши новый объект в тот же массив `PROTOCOLS`: `type: 'file'` для скачиваемого конфига или `type: 'link'` для копируемой ссылки с QR-кодом.
